# Sheikh Noor Uddin Bashar - Personal Portfolio

A responsive one-page portfolio inspired by the dark, gradient-based portfolio design shown in the reference screenshots.

## Files

- `index.html` — portfolio content and structure
- `style.css` — complete responsive styling
- `script.js` — mobile navigation, scroll highlighting, reveal animations and dynamic footer year

## Run

Simply open `index.html` in a browser.

For VS Code, you can also use the Live Server extension.

## Personal Information Used

The content is based on the uploaded resume, including education, projects, skills, research, development experience, extracurricular activities, certifications, contact information and availability.

## Profile Photo

The hero currently uses a simple `SN` placeholder because the resume did not provide a profile photo. Replace the `.profile-placeholder` element in `index.html` with an `<img>` if you want to use your own photo.
