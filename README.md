# ▶️ How to Run

## Option 1 — Browser

Clone the repository:

```bash
git clone https://github.com/sheikhnoor1/YOUR-PORTFOLIO-REPOSITORY.git
```

Open the project folder and double-click:

```text
index.html
```

The portfolio will open in your browser.

---

## Option 2 — VS Code + Live Server

1. Open the project in **VS Code**.
2. Install the **Live Server** extension.
3. Open `index.html`.
4. Right-click the file.
5. Select **Open with Live Server**.

The portfolio will then run in your browser.
